# 🏫 Quản lý Trường Tiểu học

Một dự án cá nhân được thực hiện với mục đích học tập, thực hành lập trình web và thử nghiệm xây dựng một hệ thống quản lý trường tiểu học.

Dự án lấy cảm hứng từ các hoạt động quen thuộc trong môi trường trường học, tập trung vào việc quản lý lớp học, học sinh, điểm số và các hoạt động giảng dạy.

## ✨ Một số chức năng

**Giáo viên**
- Xem thông tin tổng quan.
- Quản lý danh sách lớp và học sinh.
- Điểm danh học sinh.
- Nhập và quản lý điểm các môn học.
- Đánh giá năng lực và phẩm chất.
- Xem thời khóa biểu.
- Quản lý đơn xin nghỉ.
- Theo dõi thông báo.

**Học sinh**
- Xem thông tin cá nhân.
- Xem thời khóa biểu.
- Tra cứu kết quả học tập.
- Xem thông báo.

## 🛠️ Công nghệ sử dụng

- PHP
- MySQL / MariaDB
- HTML, CSS
- JavaScript
- Bootstrap
- XAMPP

## 🚀 Chạy dự án

1. Cài đặt [XAMPP](https://www.apachefriends.org/).
2. Clone project về máy:

   ```bash
   git clone https://github.com/vy-nguyen9/quan-ly-truong-tieu-hoc.git
   ```

3. Đưa thư mục project vào `C:\xampp\htdocs\`.
4. Khởi động Apache và MySQL trong XAMPP.
5. Tạo database và import file SQL của dự án (nếu có).
6. Cấu hình kết nối database trong `config/database.php`.
7. Truy cập:

   ```text
   http://localhost/ql_truong_tieuhoc/
   ```
